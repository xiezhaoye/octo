# Octo

原生 macOS 文件管理应用。Swift + AppKit，文档预览使用系统 WebKit；无第三方运行时或网络依赖。当前发布版 0.5.0，默认原生浅色。

## 构建与运行

开发环境：Xcode 与 Swift；最低部署版本 macOS 14。当前构建和验收机器为 Apple Silicon、macOS 27.0.1。

```sh
cd /Users/admin/project/octo/NativeFileManager
zsh build.sh
open build/Octo.app
```

构建脚本生成本地临时签名的 `.app`，不安装到“应用程序”，不上传或发布。也可用 Xcode 打开 Package.swift 阅读及调试工程。

## 已实现的操作

- 固定左右双屏，各自独立分组、目录和浏览模式；可以收起任意一屏，保留 48 pt 宽竖条，点击展开该屏及其全部导航分组。
- 创建、重命名、删除分组；添加和移除文件夹入口；组和入口拖拽排序。
- 侧边栏跨屏直接拖动为移动入口或分组，Option 拖动为复制配置，真实目录保持原位。移空的分组保留。
- 同一屏的同一真实文件夹只保留一个入口；再次拖入另一组时转移归属。不同屏可以分别保存入口。
- 原生列表、分栏、图标视图。列表可以逐级展开、全部展开和全部收拢；符号链接不参与递归展开，避免循环。
- 快速预览、系统默认程序打开文件；图标模式为图片和 PDF 异步生成缩略图，其他文件使用系统图标。
- 真实文件复制、移动、新建文件夹、重命名和移入系统废纸篓。跨屏拖动实际文件默认移动，Option 为复制。
- 同名冲突可选择保留两者、跳过、替换或取消剩余项目。文件夹替换为整个目标替换，不是合并。
- 替换前保留旧目标，成功后将旧目标备份移入废纸篓。失败时尝试恢复；备份未能回收或恢复时，显示其路径。
- 文件操作在后台执行。取消仅停止剩余项目，当前项目会先完成。
- 右键菜单顶部依次提供复制完整路径、复制目录路径、在默认终端打开；右键执行自定义 zsh 命令，命令名称、脚本和适用对象可在设置中编辑。
- “设置 → 更换皮肤”提供原生浅色、深色工作台、温暖档案柜、黑白目录台，切换不清空工作区。
- 保存分组、顺序、目录、浏览模式、隐藏项目开关、分屏收起状态、皮肤和命令。

## 分栏文档预览与编辑

仅在分栏视图中，选中 Markdown、HTML、TXT 或 JSON 文件，会在当前屏最右侧显示文档区域，不打开独立编辑窗口。Markdown、HTML、JSON 支持预览、源码编辑和分屏，标签在顶部单行居中；保存位于最左侧，右侧刷新图标重新载入。TXT、YAML、TOML 等纯文本直接进入编辑，不显示预览与分屏标签。⌘S 保存。JSON 支持树形预览、语法错误提示和格式化。常见图片在同一右侧区域原生预览，保持比例适应区域；图片为只读，不显示保存或编辑入口。

图片预览右侧的网格按钮切换到当前文件夹的图片缩略图总览，浮动上箭头或键盘 ↑ 同样进入总览。浮动左右箭头或键盘 ←／→ 浏览同目录上一张／下一张图片，首尾按钮自动禁用；快捷键说明与位置编号显示在底部。方向键仅在图片预览区获得焦点时生效。总览中双击某一项或选中后按回车回到单张预览，目录分栏保持不变。总览只为可见项请求小尺寸缩略图；单张预览串行解码，长边限制 2048 像素，快速切图取消过时请求。只浏览图片时无需加载文档 WebKit。总进程内存仍受图片格式、系统解码器及缩略图缓存影响。

后退和前进按已访问目录历史恢复当时的分栏链与选择；上一级保留现有父目录列，只收回右侧子目录列。

切换文件、目录、视图及关闭窗口前会询问未保存修改。目录刷新保留编辑区和目录列。文件在外部被修改或删除后会提示，并拒绝直接覆盖；可复制需要保留的内容后重新载入。支持不超过 8 MB 的 UTF-8／UTF-16 文本，保存保留 BOM 和换行格式。

右键文件夹或目录空白处的“新建文件”可创建 Markdown、TXT、JSON、HTML。文件夹右键在该文件夹内创建，空白右键在对应目录列内创建，不覆盖同名项目。分栏视图中新文件自动选中并进入编辑。

“设置 → 右键命令与排序 → 添加／编辑”可选择文件与文件夹、仅文件夹、仅文件或指定文件类型，扩展名以逗号分隔，例如 `md, markdown, txt, json, html, htm`。旧的“仅用于文件夹”配置自动兼容。列表同时列出所有内置右键命令；上下拖动内置或自定义命令可统一调整菜单顺序，重启后保留。内置命令只排序，自定义命令可编辑或移除。

Markdown 使用 GFM 排版；HTML 在隔离预览中禁用脚本、远程和相邻文件资源。当前提供源码编辑，不包含 XMark 的富文本编辑、Mermaid 或公式扩展。预览资源和依赖许可随应用离线打包，详见 [预览资源说明](EditorWeb/README.md)。

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| ⌘S | 保存分栏中的当前文档 |
| ⌘C / ⌘V | 复制 / 粘贴文件 |
| ⌘⌥V | 将剪贴板中的文件移到当前目录 |
| 空格 | 文本与图片在分栏右侧打开；其他项目使用 Quick Look |
| ⌘⇧N | 新建文件夹 |
| ⌘⌫ | 移入废纸篓 |
| ⌘⇧G | 输入路径前往文件夹 |
| ⌘⇧. | 显示 / 隐藏隐藏项目 |
| ⌘R | 刷新当前目录 |
| ⌘2 | 恢复双屏 |
| ⌘, | 设置 |
| ⌘Z | 撤销本次运行内记录的非替换移动；原位置已有项目时停止自动撤销 |

## 配置与首次使用

首次运行打开当前用户的主目录，两屏分组均为空。点击列表末尾的“＋ 新建分组”创建分组，再点击名称旁边的加号选择文件夹入口；右键可将当前目录加入选定组。

配置默认保存在 `~/Library/Application Support/DualPane/workspace.json`。配置读取失败时会询问是否使用默认配置，并先备份原文件。测试可以通过 `--state-dir <目录>` 使用隔离配置。

## 自定义命令

命令通过 `/bin/zsh -lc` 执行，工作目录是当前屏目录。占位符会作为 Shell 参数进行转义，支持包含空格和引号的文件名：

| 占位符 | 含义 |
| --- | --- |
| `{path}` | 首个选中项目；没有选择时为当前目录 |
| `{paths}` | 所有选中项目，分别转义 |
| `{directory}` | 当前屏目录 |

例如 `stat {path}`、`du -sh {paths}`。输出窗口最多保存 2 MB 文本；关闭后释放窗口数据。

Termius 目前提供“复制目录路径并打开应用”，没有将本地目录自动切换为 Termius 的 SSH 会话。默认 Terminal 支持传入目录打开。

## 验证

```sh
python3 check-build.py test
```

核心测试覆盖导航入口移动和 Option 复制、每屏唯一归属、整组复制、失败时不改来源配置、拖拽排序、状态序列化、路径转义、真实文件复制移动、同名冲突、替换备份与递归搜索。

原生窗口验收通过显式测试参数运行，只使用指定目录中的测试资料，截图和结果保存在 `build/verification/`。它验证原生控件和状态切换，不等同于实体鼠标拖拽自动化测试。

## 当前边界

- 仅在当前机器验证过；尚未制作 Intel / 通用二进制、安装包或公证版本。
- 完整的跨卷、NAS、iCloud 未下载占位文件、权限失败等复杂环境，仍需专项实机验证；目前不承诺其性能指标。
- 非替换移动提供基础撤销；复制、替换及删除尚无统一的 App 内撤销历史。删除可从系统废纸篓恢复。
- 快速连续移动多个文件时，操作进度以项目数量显示，不显示当前单个文件的字节进度。
- 不支持三屏、上下布局及拖动分屏重排。

需求依据为项目上级目录的《产品需求分析.md》，视觉规范见 DESIGN.md。

## 0.2 界面调整

分组栏可调宽、可收起为竖条并保存状态；淡色分组标题整行可点，加号紧跟名称。唯一新增组按钮位于最后一组下方，与标题区域等宽并加高。文件区导航工具栏加高，路径操作紧跟最后一级目录；搜索改为放大镜弹层。常驻项目数栏移除，全部展开与收拢保留在列表右键。分栏超宽后支持横向滚动及自动跟随新列。

## 0.3 交互调整

新建分组固定在左下角；标题靠近展开箭头，加号靠右。分栏内的列表将横向触控板/鼠标事件路由到整个分栏画布，并支持 Shift + 滚轮。窗口按钮右侧显示 Octo 与用户提供的 Logo；打包产物为 `build/Octo.app`。沿用旧 bundle id 和配置目录以保留已有工作区。

## 0.4 界面精简

主界面仅保留 Octo 文字名称，移除搜索入口与执行逻辑。分组标题按实际文字高度居中，加号靠右。三种视图、隐藏和收屏图标统一为 19 pt；双屏使用 4 pt 分界；标题栏仅保留缩小后的设置按钮。列表名称、修改日期、大小表头支持双向排序，已展开子目录与选中项保持。文件夹大小显示“—”，不递归统计。

## 0.4.1 视觉修正

点击分组标题不会改变箭头、加号的强调色。收起分组栏不再保留分隔线占位。三个视图按钮使用独立的 AppKit 控件按图形对齐区域居中绘制。Dock 与打包应用图标改用用户提供的透明 PNG。

## 0.4.2 标题栏 Logo

Octo 文字前显示透明 Logo，与 Dock 使用同一透明资源，图文垂直居中，不添加底色。

## 文件夹颜色标签

文件区和侧栏的文件夹右键菜单提供“颜色标签”，内置红、橙、黄、绿、蓝、紫、灰七色。点击色块添加，已添加的颜色显示勾选，再次点击移除；支持多色叠加及多选文件夹批量设置。列表、分栏、图标视图和侧栏显示鲜艳色点，并按主标签为文件夹图标着色。

颜色按文件夹路径保存在 Octo 工作区中，与访达标签独立，不读取或修改访达标签。色点仅显示纯色填充，不绘制外圈。“颜色标签”也出现在设置的右键命令排序列表中。

目录列表、分栏底部预留 72 像素可滚动空白区，图标视图也增加底部留白，供右键操作当前目录。路径栏在复制路径、终端右侧增加竖线、新建文件夹及新建文件图标，后者下拉选择 Markdown、HTML、TXT、JSON；路径栏操作始终在当前显示的目录新建。图片预览两侧各留出导航区域，仅显示箭头图标，不覆盖图片，无圆形背景。

## 系统材质、菜单与设置

侧栏使用系统 sidebar 材质，导航区使用 header 材质；系统启用“降低透明度”时自动使用实色。文件列表与预览正文仍为稳定底色。侧栏选中图标保持自身颜色，保留文件夹的独立颜色标签。

设置按“外观、右键菜单、关于与更新”分类。右键命令按用途分组，分隔线只出现在有内容的组之间。拖动排序支持组内调整和跨组移动。文件的“打开方式”列出系统登记的可用 App；多选时取交集，“选择其他应用”只影响本次打开。

## 在线更新

“关于与更新”显示当前版本／构建号，手动检查 `https://octo-dl.xiezhaoye.site/latest.json`。发现新版本后，先下载并校验，随后由用户点击“安装并重启”。检查失败可重试，系统版本不足、架构不匹配、下载校验失败时不安装。

更新包验证包括固定 HTTPS 下载域名、字节数、SHA-256、ZIP 路径及展开大小、应用 bundle id／版本／可执行文件架构与代码签名。当前发布包仍为临时签名开发版，包的真实性依赖 HTTPS 更新服务；没有 Developer ID 公证或独立的更新清单签名。

安装在退出保存检查通过后启动辅助进程，在当前 App 同级暂存并替换；旧 App 保留为 `.Octo-backup-<UUID>.app`，替换失败会恢复原 App。该流程不覆盖工作区配置。只支持可写安装目录，处于 App Translocation 或只读目录时会提示先移动应用。网络验收和辅助进程验收只使用独立测试目录与 App 副本。

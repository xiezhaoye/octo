# Octo

原生 macOS 文件管理应用。Swift + AppKit，无网页容器、无第三方运行时或网络依赖。当前为本地开发版 0.4.2，默认原生浅色。

## 构建与运行

开发环境：Xcode 与 Swift；最低部署版本 macOS 14。当前构建和验收机器为 Apple Silicon、macOS 27.0.1。

```sh
cd /Users/admin/project/myfolder/NativeFileManager
zsh build.sh
open build/Octo.app
```

构建脚本生成本地临时签名的 `.app`，不安装到“应用程序”，不上传或发布。也可用 Xcode 打开 Package.swift 阅读及调试工程。

## 已实现的操作

- 固定左右双屏，各自独立分组、目录和浏览模式；可以收起任意一屏，保留 48 pt 宽竖条，点击展开该屏及其全部导航分组。
- 创建、重命名、删除分组；添加和移除文件夹入口；组和入口拖拽排序。
- 侧边栏跨屏直接拖动为移动入口或分组，Option 拖动为复制配置，真实目录保持原位。移空的分组保留。
- 同一屏的同一真实文件夹只保留一个入口；再次拖入另一组时转移归属。不同屏可以分别保存入口。
- 原生列表、分栏、图标视图。列表可以逐级展开、全部展开和全部收拢；符号链接不参与递归展开，避免循环。
- 快速预览、系统默认程序打开文件；图标模式为图片和 PDF 异步生成缩略图，其他文件使用系统图标。
- 真实文件复制、移动、新建文件夹、重命名和移入系统废纸篓。跨屏拖动实际文件默认移动，Option 为复制。
- 同名冲突可选择保留两者、跳过、替换或取消剩余项目。文件夹替换为整个目标替换，不是合并。
- 替换前保留旧目标，成功后将旧目标备份移入废纸篓。失败时尝试恢复；备份未能回收或恢复时，显示其路径。
- 文件操作在后台执行。取消仅停止剩余项目，当前项目会先完成。
- 复制完整路径、在默认终端打开；右键执行自定义 zsh 命令，命令名称、脚本和适用对象可在设置中编辑。
- “设置 → 更换皮肤”提供原生浅色、深色工作台、温暖档案柜、黑白目录台，切换不清空工作区。
- 保存分组、顺序、目录、浏览模式、隐藏项目开关、分屏收起状态、皮肤和命令。

## 配置与首次使用

首次运行打开当前用户的主目录，两屏分组均为空。点击列表末尾的“＋ 新建分组”创建分组，再点击名称旁边的加号选择文件夹入口；右键可将当前目录加入选定组。

配置默认保存在 `~/Library/Application Support/DualPane/workspace.json`。配置读取失败时会询问是否使用默认配置，并先备份原文件。测试可以通过 `--state-dir <目录>` 使用隔离配置。

## 自定义命令

命令通过 `/bin/zsh -lc` 执行，工作目录是当前屏目录。占位符会作为 Shell 参数进行转义，支持包含空格和引号的文件名：

| 占位符 | 含义 |
| --- | --- |
| `{path}` | 首个选中项目；没有选择时为当前目录 |
| `{paths}` | 所有选中项目，分别转义 |
| `{directory}` | 当前屏目录 |

例如 `stat {path}`、`du -sh {paths}`。输出窗口最多保存 2 MB 文本；关闭后释放窗口数据。

Termius 目前提供“复制目录路径并打开应用”，没有将本地目录自动切换为 Termius 的 SSH 会话。默认 Terminal 支持传入目录打开。

## 验证

```sh
python3 check-build.py test
```

核心测试覆盖导航入口移动和 Option 复制、每屏唯一归属、整组复制、失败时不改来源配置、拖拽排序、状态序列化、路径转义、真实文件复制移动、同名冲突、替换备份与递归搜索。

原生窗口验收通过显式测试参数运行，只使用指定目录中的测试资料，截图和结果保存在 `build/verification/`。它验证原生控件和状态切换，不等同于实体鼠标拖拽自动化测试。

## 当前边界

- 仅在当前机器验证过；尚未制作 Intel / 通用二进制、安装包或公证版本。
- 完整的跨卷、NAS、iCloud 未下载占位文件、权限失败等复杂环境，仍需专项实机验证；目前不承诺其性能指标。
- 非替换移动提供基础撤销；复制、替换及删除尚无统一的 App 内撤销历史。删除可从系统废纸篓恢复。
- 快速连续移动多个文件时，操作进度以项目数量显示，不显示当前单个文件的字节进度。
- 不支持三屏、上下布局及拖动分屏重排。

需求依据为项目上级目录的《产品需求分析.md》，视觉规范见 DESIGN.md。

## 0.2 界面调整

分组栏可调宽、可收起为竖条并保存状态；淡色分组标题整行可点，加号紧跟名称。唯一新增组按钮位于最后一组下方，与标题区域等宽并加高。文件区导航工具栏加高，路径操作紧跟最后一级目录；搜索改为放大镜弹层。常驻项目数栏移除，全部展开与收拢保留在列表右键。分栏超宽后支持横向滚动及自动跟随新列。

## 0.3 交互调整

新建分组固定在左下角；标题靠近展开箭头，加号靠右。分栏内的列表将横向触控板/鼠标事件路由到整个分栏画布，并支持 Shift + 滚轮。窗口按钮右侧显示 Octo 与用户提供的 Logo；打包产物为 `build/Octo.app`。沿用旧 bundle id 和配置目录以保留已有工作区。

## 0.4 界面精简

主界面仅保留 Octo 文字名称，移除搜索入口与执行逻辑。分组标题按实际文字高度居中，加号靠右。三种视图、隐藏和收屏图标统一为 19 pt；双屏使用 4 pt 分界；标题栏仅保留缩小后的设置按钮。列表名称、修改日期、大小表头支持双向排序，已展开子目录与选中项保持。文件夹大小显示“—”，不递归统计。

## 0.4.1 视觉修正

点击分组标题不会改变箭头、加号的强调色。收起分组栏不再保留分隔线占位。三个视图按钮使用独立的 AppKit 控件按图形对齐区域居中绘制。Dock 与打包应用图标改用用户提供的透明 PNG。

## 0.4.2 标题栏 Logo

Octo 文字前显示透明 Logo，与 Dock 使用同一透明资源，图文垂直居中，不添加底色。

支持哪些 Mac？

当前安装包面向 Apple Silicon（M 系列芯片），要求 macOS 14 或更新版本。源码公开，可自行构建；尚未提供经过验证的 Intel 安装包。

下载后怎么安装？是否经过 Apple 公证？

解压 ZIP，将 Octo.app 拖到“应用程序”后打开。当前 0.4.2 为临时签名开发版，尚未经过 Apple 公证。若系统阻止首次启动，尝试打开后进入“系统设置 → 隐私与安全性”，使用系统提供的“仍要打开”。仅在确认下载来源可信时操作。

需要什么权限？我的数据会去哪？

访问桌面、文稿、下载目录或外接磁盘时，macOS 可能要求授权。文件留在原位置，分组、布局和设置保存在本机。Octo 没有账号和应用内云同步；自定义命令和终端会以当前用户权限运行，请只添加自己信任的命令。

拖动侧栏文件夹，会移动真实文件吗？

不会。侧栏拖动只整理入口配置，跨屏默认移动入口，按住 Option 复制入口。文件区里的拖动则是实际磁盘操作，跨屏默认移动，按 Option 复制；同名冲突会弹窗选择。

免费吗？能参与开发吗？

免费，源码采用 MIT License。可以在 GitHub 阅读代码、提交问题或改进建议。当前版本处于早期阶段；跨卷、NAS、iCloud 占位文件和大目录尚未完成专项压力测试。
